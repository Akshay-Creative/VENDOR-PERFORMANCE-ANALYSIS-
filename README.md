# Inventory Data Ingestion & Analysis Pipeline

An automated data ingestion pipeline and exploratory analysis tool built with Python, Pandas, SQLAlchemy, and SQLite. This project ingests large-scale retail inventory, purchasing, and sales datasets into a structured SQLite database and performs exploratory data analysis (EDA) to evaluate vendor profitability and product pricing strategies[cite: 1, 2].

---

## 📌 Objectives

* **Data Ingestion:** Automate the loading of raw CSV datasets into a relational database with structured logging and runtime tracking.
* **Vendor Profitability Analysis:** Analyze vendor sales, margins, freight costs, and excise taxes to optimize supplier selection.
* **Pricing Optimization:** Evaluate purchase prices versus selling prices across product lines and brand descriptions[cite: 2].
* **Inventory Tracking:** Calculate stock turnover rates and sales-to-purchase ratios to manage inventory efficiency[cite: 2].

---

## 🗄️ Database Architecture & Data Summary

The ingestion module loads raw datasets into a local SQLite database (`inventory.db`)[cite: 1, 2]. The core tables in the database include:

| Table Name | Record Count | Description |
| :--- | :--- | :--- |
| `sales` | 12,825,363 | Transactional sales data including sales price, quantity, and excise tax[cite: 1, 2]. |
| `purchases` | 2,372,474 | Detailed purchase orders, receiving dates, and pay dates[cite: 1, 2]. |
| `end_inventory` | 224,489 | Ending inventory snapshot per store and brand[cite: 1, 2]. |
| `begin_inventory` | 206,529 | Beginning inventory snapshot per store and brand[cite: 1, 2]. |
| `purchase_prices` | 12,261 | Item purchase price catalog by vendor and volume[cite: 1, 2]. |
| `vendor_sales_summary` | 10,692 | Aggregated summary metrics for vendor performance[cite: 2]. |
| `vendor_invoice` | 5,543 | Vendor invoice records containing freight costs and pay dates[cite: 1, 2]. |

---

## ⚙️ Key Features & Pipeline Steps

### 1. Database Ingestion Pipeline
* Scans the designated `data/` folder for `.csv` source files.
* Uses SQLAlchemy engines and Pandas to replace/create SQLite tables dynamically.
* Logs execution steps, table creation status, and total runtime to `logs/ingestion_db.log`[cite: 1].

### 2. Exploratory Data Analysis (EDA)
* Connects directly to `inventory.db` using standard `sqlite3` and `Pandas` queries[cite: 2].
* Extracts vendor-specific financial and operational performance metrics[cite: 2]:
  * **Gross Profit & Profit Margins (%)**[cite: 2]
  * **Stock Turnover Rates**[cite: 2]
  * **Sales-to-Purchase Ratios**[cite: 2]
  * **Freight Costs & Excise Taxes**[cite: 2]
